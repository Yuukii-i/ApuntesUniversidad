## ¿Qué es la Web?

La World Wide Web es un sistema de distribución de documentos de hipertexto interconectados y accesibles a través de Internet.

### Historia breve

Con un navegador web, un usuario visualiza sitios web compuestos de páginas web que pueden contener texto, imágenes, videos u otros contenidos multimedia.

## Arquitectura Cliente-Servidor

El modelo cliente-servidor describe cómo interactúan los dispositivos para intercambiar información en la red.

### El Cliente

El cliente suele ser un navegador web que solicita recursos a un servidor remoto.

### El Servidor

El servidor almacena los recursos, procesa las solicitudes y atiende las peticiones recibidas.
