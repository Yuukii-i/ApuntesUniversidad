## Los Orígenes de HTML

HTML fue concebido por Tim Berners-Lee a finales de los años 80 para compartir artículos científicos.

### Las primeras especificaciones

Las especificaciones iniciales definían un conjunto básico de etiquetas de texto e hipervínculos.

## La Guerra de los Navegadores

Durante los años noventa surgieron etiquetas propietarias que dificultaron la interoperabilidad web.

### El nacimiento del W3C

El consorcio W3C se fundó para estandarizar las tecnologías fundamentales de la web y garantizar su compatibilidad futura.
